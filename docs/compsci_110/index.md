# 欢迎来到 COMPSCI 110

Introduction to Computer Science. 中文名“计算机科学导论”

虽然课程标题中有 “Introduction” 这几个字，但显而易见地这门课所带来的人数变化只会减少而不会增多。

我们不妨回想一下这门课程的第一节课前，教室外的人群数量以及他们眼中的决心；再对比一下现在每节课前的人群数量 -- 甚至没有一节 lab 来的人多 -- 哦骗你的，lab 根本没人来，XD

至于为什么这门课程具有如此强大的劝退属性，其原因从我们那两位传奇讲师的语速就可以立刻推断出来。他们洪亮且迅速的讲解，显著地增加了讲座回放的观看率，同时解决了同学们可能需要二倍速观看的核心痛点 -- 自动常驻二倍速，保证每一名观看讲座的学生在数分钟内即可进入昏迷状态

> 一名同学连续观看了 20 小时的 COMPSCI 110 讲座回放，这是他的大脑发生的变化...
